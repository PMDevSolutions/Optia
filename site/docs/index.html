Every Optia check, explained

Optia scores 25 on-page SEO checks across meta tags, content, links, images, and technical SEO. Each guide below covers what the check measures, why it matters, and exactly how to fix it.

Meta SEO

  • Page titles and your target keywordPage has a title tag · Title length is optimal (50-60 characters) · Title contains target keyword
  • Meta descriptions that earn the clickPage has a meta description · Meta description length is optimal (120-155 characters) · Meta description contains target keyword
  • Keywords in the URLURL contains target keyword
  • Open Graph tags and social sharingOpen Graph title and description are present · Open Graph image is set

Content

  • The H1 headingPage has an H1 heading · H1 contains target keyword
  • Heading hierarchyHeading hierarchy is correct
  • Keywords in H2 headingsH2 headings contain target keyword
  • Keyphrase densityKeyphrase density is optimal (0.5%-2.5%)
  • Keywords in the introductionKeyphrase appears in introduction
  • Content lengthPage has sufficient content

Links

  • Internal linksPage has internal links
  • Outbound linksPage has outbound links

Images

  • Image alt textAll images have alt text
  • Next-gen image formatsImages use next-gen formats (WebP/AVIF)
  • Image file sizeImages are under 500KB

Technical SEO

  • Canonical URLsPage has a canonical URL
  • The lang attributePage has a language attribute
  • Schema markup (structured data)Schema markup is present
  • Code minificationCode is minified
