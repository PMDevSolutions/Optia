Keywords in the URL

URL contains target keyword

What this check looks at

Optia checks whether the page's URL (typically the final slug) contains your target keyword.

Why it matters

A descriptive, keyword-bearing URL is a small ranking signal and a large trust signal: people are more likely to click a URL that visibly matches what they searched for, and shared links carry their own context.

How to fix it

  • Use short, lowercase, hyphen-separated slugs: /trail-running-shoes, not /p?id=4821.
  • Include the main keyword once; skip filler words (a, the, and).
  • When renaming an existing URL, add a 301 redirect from the old address so you keep its accumulated equity.
Fix it with Optia: Optia can suggest an SEO-friendly slug for the page from your keyword.
