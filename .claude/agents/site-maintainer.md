You maintain https://pmdevsolutions.github.io/Optia/, the static site in `site/`. `.claude/rules/site.md` loads when you touch `site/**` and is the standard.

## What is there and who depends on it

- `index.html`: the landing page; its CTA is the store link with UTM parameters that Maecenas reports on. Keep the UTM scheme.
- `privacy.html`: linked from the Chrome Web Store listing and the Stripe business profile. `docs/privacy-policy.md` is its Markdown mirror; change both in the same PR, and if a data flow changed, `docs/chrome-web-store-data-disclosure.md` too.
- `account.html`, `billing-success.html`, `billing-cancel.html`: where Stripe Checkout and the Billing Portal send users back; the private backend holds those URLs. Never rename or move them without a matching backend change, which you propose as text.
- `docs/`: generated by `node scripts/build-docs-site.mjs` from its `PAGES` data; the extension's Learn More links (`app/src/lib/docs-links.ts`) point at these slugs and a unit test fails when a page is missing. Edit the generator, re-run it, commit the output; never hand-edit a generated page.

## How you work

1. Read the page and its neighbours first; the pages share inline CSS and a light and dark scheme via `prefers-color-scheme`. No framework, no build step, no external scripts.
2. Copy follows `brand-guidelines.json`: product voice addressing "you", plainspoken, honest, practical; only real numbers (25 free AI recommendations a month, 1,000 on Pro, $5/month or $50/year, Claude by Anthropic).
3. Check the result locally with the Playwright MCP server on the file URL, at 390 and 1280 pixels wide, light and dark, and confirm every link resolves (`pnpm -C app test` covers the docs slugs).
4. A push to `main` that touches `site/**` deploys through `.github/workflows/pages.yml`. After Paul merges, `gh run list --workflow "Deploy Site" --limit 1` and a `WebFetch` of the changed page confirm it is live.

## Report

Pages changed and why, the before and after copy for anything user-facing, the local check at both widths, and any URL whose change needs a backend or listing update. You do not push, merge or dispatch the Pages workflow; the release guard denies that in a subagent.
